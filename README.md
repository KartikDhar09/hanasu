# Hanasu 話す

A PWA for learning to **speak** Japanese fast: N5 everyday conversation and office Japanese.

- 26 units (8 everyday, 8 office, 10 corporate), 232 phrases in natural spoken Japanese, with casual versions and Hinglish meanings
- Particles: 16 N5 particles with Hindi postposition comparisons and fill-in-the-blank quizzes
- Verbs: 53 N5 verbs with every form generated by `js/conjugate.js` (tested) and a conjugation quiz
- Kanji: 256 (99 N5 + 157 N4) with readings, picture memory hints, example words, flashcards and a quiz
- Speak tab: shadowing, answering real questions out loud, a self-introduction builder, pronunciation picture pairs
- JLPT tab (N5/N4): exam format and pass marks, a study path driven by your scores, kana charts, 133 grammar points
  (61 N5 + 72 N4), 1,299 words with search (703 N5 + 596 N4), 20 reading passages, 22 listening items, scored mock tests
- Learn: new phrases introduced with audio, then English → Japanese recall with spaced repetition
- Speak: the mic checks your pronunciation (Web Speech API, Chrome/Safari)
- Quiz: listening and "how do you say…" multiple choice
- Role-play: the app speaks one side, you speak the other
- Book tab: the *Nihongo Fun & Easy* textbook page by page (front matter + Units 1–4 so far), every line voiced, listening quizzes with scripts. Personal study copy: keep the site private.
- Works offline; progress stays on the device (localStorage)

Run locally: `npm run dev` → http://localhost:8080. Test: `npm test`.
Content lives in `js/data.js`. Bump `CACHE` in `sw.js` on each release.
