# Hanasu 話す

A PWA for learning to **speak** Japanese fast: N5 everyday conversation and office Japanese.

- 26 units (8 everyday, 8 office, 10 corporate), 232 phrases in natural spoken Japanese, with casual versions and Hinglish meanings
- Particles: 16 N5 particles with Hindi postposition comparisons and examples
- Verbs: 53 N5 verbs with every form generated by `js/conjugate.js` (tested) and audio for each form
- Kanji: 256 (99 N5 + 157 N4) with readings, picture memory hints, example words and flashcards
- Speak tab: shadowing, answering real questions out loud, a self-introduction builder, pronunciation picture pairs
- JLPT tab (N5/N4): exam format and pass marks, a study path, kana charts, 133 grammar points
  (61 N5 + 72 N4), 1,299 words with search (703 N5 + 596 N4), 20 reading passages, 22 listening items, scored mock tests
- Learn: new phrases introduced with audio, then English → Japanese recall with spaced repetition
- Speak: the mic checks your pronunciation (Web Speech API, Chrome/Safari)
- Paths (N5·N4 and Fluent): step-by-step levels. No quizzes or level tests since v6.0: you mark a level complete
  yourself, in any order, and can undo it. The full N5/N4 mock tests are the only tests left.
- Role-play: the app speaks one side, you speak the other
- Book tab: the *Nihongo Fun & Easy* textbook page by page (front matter + Units 1–4 so far), every line voiced, listening quizzes with scripts. Personal study copy: keep the site private.
- Works offline; progress stays on the device (localStorage)
- Login wall: the whole app (book included) is visible only after logging in (`middleware.js`, `api/auth.js`).
  Accounts: unique name + password; anyone with the link can sign up. Needs these Vercel environment variables:
  `SESSION_SECRET` (32+ random characters) and Upstash Redis (`KV_REST_API_URL`, `KV_REST_API_TOKEN`).
  Optional `INVITE_CODE`: once set, sign-up needs that code (the field appears on the login page by itself).
  👥 Board (#board, header button): for each person, what is done / current / left in every tab (worked out
  from the two path levels via the generated `js/path-summary.js`; Book pages count once marked done), passed
  full mocks, plus a feed. Regenerate the summary after editing a path: `node scripts/path-summary.mjs`. The account is the source of truth for completed levels (`/api/board`); a device sends one change at a time and keeps an offline copy.
  Forgot a password: `node scripts/reset-password.mjs "<name>"` (see the file for the keys it needs)

- Interface icons (tabs, header, buttons, hub cards, board) are inline SVG from Lucide in `js/icons.js`, generated
  by `scripts/icons.mjs` (see the file for how to regenerate). Emoji stay where they are content (vocab, food, units).

Run locally: `npm run dev` → http://localhost:8080. Test: `npm test`.
Content lives in `js/data.js`. Bump `CACHE` in `sw.js` on each release.
